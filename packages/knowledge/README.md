# Base de conhecimento

- `regulatorio/` — resumos próprios (não cópias integrais) de LBI (Lei 13.146/2015, art. 63), ABNT NBR 17225,
  eMAG, WCAG 2.2, Decreto 5.296/2004, instrumento de avaliação do MEC e normas setoriais (CONSTITUICAO §8.5).
  Cada arquivo com fonte, data de revisão e responsável.
- `objecoes/` — biblioteca de objeções e respostas aprovadas ("já temos plugin", "não é prioridade", preço…).

Esses arquivos são indexados no pgvector e citados pelos agentes. A plataforma não emite parecer jurídico.
